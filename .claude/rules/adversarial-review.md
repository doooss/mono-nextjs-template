# Adversarial Review (적대적 리뷰)

출고 게이트 2단계. **필수** — 변경 크기와 무관하게 최소 1 round. 목적 = 구현자가 놓친 실패 경로를 찾아 `예외 케이스` 로 남기는 것.

## 방법

- [`adversarial-reviewer`](../agents/adversarial-reviewer.md) 서브에이전트 (새 컨텍스트). 구현한 세션이 스스로 리뷰하지 않는다.
- 주는 것: diff 범위 · task 파일 (목표 / 범위 / Acceptance) · 영향 받는 현재 사양 경로.
- 주지 않는 것: 구현자의 설명 · 결론 (앵커링 방지).
- 공격 면: acceptance 미충족 · 경계 / 예외 입력 · 보안 · 사양 드리프트 (코드 ≠ `docs/specs/`) · 회귀 · (FE) 화면 상태 / a11y / 모바일.

## 판정

finding 마다 하나:

| 판정 | 조건                                                   |
| ---- | ------------------------------------------------------ |
| 수용 | 결함 인정 → 수정                                       |
| 반박 | 결함 아님 — 근거 필수 (코드 경로 · 테스트 · 사양 조항) |
| 이월 | 범위 밖 — 새 task. blocking 은 이월 불가               |

수정 후 새 컨텍스트로 재리뷰 → 미해결 blocking 0 까지. 3 round 를 넘으면 사용자에게 넘긴다. 반박이 설계 선택이면 ADR 후보.

## 기록

- task `## 예외 케이스` = finding 전체의 압축본.
- 동작으로 남는 예외 (예: "빈 목록이면 200 + `[]`") 는 현재 사양 `## 예외 케이스` 에도.
- frontmatter `review: passed (YYYY-MM-DD, rounds N)`.

```markdown
## 예외 케이스

| #   | 케이스                      | 판정 | 처리 · 근거                                                                 |
| --- | --------------------------- | ---- | --------------------------------------------------------------------------- |
| 1   | 세션 만료 중 제출 → 빈 화면 | 수용 | 로그인으로 리다이렉트, `login-form.test.tsx › redirects on expired session` |
| 2   | 더블 클릭 중복 제출         | 반박 | 제출 중 버튼 disabled (`login-form.tsx`)                                    |
| 3   | 대량 import 타임아웃        | 이월 | 261121_004                                                                  |
```
